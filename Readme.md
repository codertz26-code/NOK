## 📝 Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| SESSION_ID | Your WhatsApp session (sila~base64) | - |
| OWNER_NUMBER | Owner phone number | 255650034217 |
| MODE | Bot mode (public/private/inbox/group/self) | public |
| PREFIX | Command prefix | . |
| ANTI_LINK | Delete group links | true |
| ANTI_CALL | Block calls | false |
